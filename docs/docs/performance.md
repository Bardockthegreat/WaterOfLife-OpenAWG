# Performance Expectations

## Environmental Conditions
- Temperature: 24–30°C
- Humidity: 60–80%
- Operation: 24/7 continuous

## Expected Output
- 1 × TEC1-12706: 0.3–0.6 L/day
- 2 × TEC1-12706: 0.6–1.2 L/day
- Peak (30°C / 80% RH): up to ~1.4 L/day

## Notes
- Output varies ±30% based on airflow, duct sealing, and frost.
- Running Peltiers at 9–10 V improves efficiency.
- Proper hot-side cooling is essential for stable performance.
